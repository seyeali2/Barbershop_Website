# Sunu Cut 💈

Sunu Cut is a web application designed for a barbershop.  
It allows users to create an account, book appointments, search for information and leave reviews.

## Features

- User registration and login
- Appointment booking
- Search functionality
- User reviews
- Admin management
- User logout

## Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## Database

The application uses a MySQL database to store and manage information such as users, appointments and reviews.

## Purpose

This project was created to practice web development and database management by building a complete and interactive barbershop website.
